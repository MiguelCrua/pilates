# Aulas de Pilates

Gerador de aulas de Pilates de 45 min, 1h ou 1h30, por nível (Fácil, Intermédio, Difícil), com exercícios escolhidos ao acaso.

- Toca num exercício para ver a descrição.
- 🔄 troca um exercício; **+** adiciona um exercício a uma fase.
- Os exercícios adicionados ficam guardados no browser (localStorage).

Página estática: basta o `index.html`. Para publicar, ativa o GitHub Pages em *Settings → Pages*.
